# Article To Video

Use this reference when the source is a copied article, newsletter, thread, PDF text, or long screenshot.

## Extraction

Create a compact source map before scripting:

```text
title:
audience:
core claim:
reader pain:
proof/examples:
framework:
best lines:
call to action:
```

If the user provides only screenshots, be explicit that content precision is limited. Ask for copied text when the final video must preserve exact argument order or wording.

## Short-Video Script Pattern

Use this 7-part structure for knowledge/self-improvement/business content:

1. Hook: pain, contradiction, or strong claim.
2. Reframe: name the real problem.
3. Definition: explain the concept in one sentence.
4. Step 1: first actionable move.
5. Step 2: second actionable move.
6. Step 3 or example: make it concrete.
7. Close: one memorable sentence or CTA.

## Segment Schema

Use this schema unless a project already has one:

```json
[
  {
    "start": 0,
    "end": 4.5,
    "type": "hook",
    "subtitle": "Short on-screen text",
    "voiceover": "Longer spoken line if needed",
    "visual": "What appears on screen",
    "motion": "How it moves"
  }
]
```

## Timing Defaults

- 30 seconds: 5-6 segments.
- 45 seconds: 7 segments.
- 60 seconds: 8-9 segments.
- Hook: 0-4 seconds.
- Definition: 5-8 seconds.
- Each method step: 5-8 seconds.
- Close: 4-7 seconds.

## Copy Rules

- Keep the article's core claim intact.
- Compress examples, but preserve the best concrete example if it proves the point.
- Do not over-generalize a specific article into generic advice.
- Use the user's voice when clear; otherwise write concise spoken Chinese or English based on the source language.
