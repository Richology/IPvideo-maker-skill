# Publish Review

Use this reference after the user has published a video or simulated a review.

## Data To Request

```text
platform:
publish time:
title:
cover text:
duration:
views:
3-second retention:
completion rate:
average watch time:
likes:
saves:
comments:
shares:
follower conversions:
audience comments:
```

## Diagnosis

Pick one primary bottleneck:

- Hook: low 3-second retention.
- Promise mismatch: high starts but low completion and negative comments.
- Pacing: average watch time drops before core value.
- Clarity: saves low despite views.
- Packaging: low views from existing audience.
- CTA: engagement low despite completion.

## Output Format

Give:

1. What likely happened.
2. The one highest-leverage fix.
3. A revised hook/title/cover or first 5-second script.
4. The next A/B test.
